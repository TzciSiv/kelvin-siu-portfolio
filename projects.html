Object detection

Person, Car, Dog & Bicycle Detector

A Flask web app that serves a YOLO detector for common VOC objects and returns annotated predictions from uploaded images.

  • ProjectBuilt an object-detection demo for person, car, dog, and bicycle recognition.
  • ResultReached 0.9497 mAP@50, 0.9368 precision, and 0.9120 recall after 100 training epochs.
  • HowFine-tuned YOLO on a VOC-format dataset with 33,290 images across train, validation, and test splits.
  • ChallengeKept the app reproducible by separating model weights, uploaded images, prediction outputs, and Docker runtime setup.
  • LearnedEvaluated detection quality with mAP, PR/F1 curves, confusion matrices, and visual prediction samples before trusting the demo.
